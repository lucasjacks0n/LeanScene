What it does

LeanScene finds every shot transition in a video: hard cuts, and gradual ones such as dissolves and fades. Drop a video above to see them on a timeline, each with the frame before and after.

The whole model is 1.6 MB, small enough to ship inside this page.

How it works

  1. Every frame is decoded and shrunk to 100×100 pixels.
  2. A small network turns each frame into a short description, once.
  3. A second network reads those descriptions in order and labels each frame same, cut or fade.

Both run on your graphics card through WebGPU, or on the CPU where that is missing.

Use it yourself

Python

pip install git+https://github.com/lucasjacks0n/LeanScene
leanscene video.mp4

Node.js

npm install leanscene
npx leanscene video.mp4

Code, weights and training labels on GitHub · npm. The paper is in preparation.
